# 🗳️ E-Voting for Community DAOs

A secure, transparent and decentralized voting system for DAOs built on Stacks blockchain.

## 🎯 Features

- ✨ Create time-bound proposals
- 🔒 Secure one-vote-per-member system
- ✅ Verified voter registration
- 📊 Automatic vote tallying
- 🔍 Transparent voting records

## 🚀 Getting Started

### Prerequisites

- Clarinet
- Stacks wallet

### Contract Functions

1. `initialize-contract`: Set up the contract (admin only)
2. `register-voter`: Add verified voters (admin only)
3. `create-proposal`: Create new voting proposal
4. `cast-vote`: Cast vote on active proposal
5. `get-proposal`: View proposal details
6. `close-proposal`: Finalize voting results

## 📖 Usage Example

1. Admin initializes contract
2. Admin registers verified voters
3. Verified members create proposals
4. Members cast votes during proposal window
5. Proposal automatically closes after end block
6. Results are permanently stored on-chain

## 🔐 Security

- Non-transferable voting rights
- One vote per proposal
- Time-bound voting windows
- Only verified members can participate
